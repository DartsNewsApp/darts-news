DARTS NEWS — SETTING UP ONLINE PLAY (one time, about 10 minutes, free)

1. Go to https://console.firebase.google.com and sign in with a Google account.
2. Click "Create a project" (or "Add project"). Name it darts-news.
   Turn OFF Google Analytics (not needed). Click Create project, then Continue.
3. In the left menu open Build > Realtime Database. Click "Create Database".
   Location: Belgium (europe-west1). Choose "Start in locked mode". Click Enable.
4. Open the "Rules" tab, delete everything there and paste this, then click Publish:

{
  "rules": {
    "rooms": {
      "$code": {
        ".read": "$code.matches(/^DN-[0-9]{4}$/)",
        ".write": "$code.matches(/^DN-[0-9]{4}$/)"
      }
    },
    "events": {
      "$code": {
        ".read": "$code.matches(/^T-[0-9]{4}$/)",
        ".write": "$code.matches(/^T-[0-9]{4}$/)"
      }
    },
    "pub": {
      ".read": true,
      "$code": {
        ".write": "$code.matches(/^T-[0-9]{4}$/)"
      }
    }
  }
}

   (If you already pasted the older, shorter rules, replace them with these:
   the "events" and "pub" parts are for live events.)

5. Open the "Data" tab. At the top is your database address, for example:
   https://darts-news-1a2b3-default-rtdb.europe-west1.firebasedatabase.app
   Copy it.
6. (Done: the address https://darts-news-default-rtdb.europe-west1.firebasedatabase.app is built into the app.)
   (To try it straight away on your own phone: open the app > Settings > Online play,
   paste the address and tap Save. Your friend would need to do the same until
   the address is built in.)

The free plan allows about 100 people connected at the same time (players and spectators together),
which is plenty for testing. For big live events with many spectators, switch the project to the
pay-as-you-go Blaze plan and set a budget alert; small events cost pennies.
